# 研究方向与进展报告

**研究方向**:Diffusion 模型的启发式推理加速(Heuristic Acceleration for Diffusion Models)

**汇报人**:Marshall
**日期**:2026 年 8 月 27 日

---

## 一、研究方向和总体目标

扩散模型的推理代价高昂:一次 50 步去噪需重复执行 28 层 Transformer 数十次。**启发式加速**(无需训练的缓存/近似技术)是当前主流降本手段,代表方法分两类:

| 族类 | 核心机制 | 代表方法 |
|------|---------|---------|
| **外推型** | 缓存各层输出与导数,用 Taylor 级数外推预测,跳过 attention/MLP | SpecA (Cache4Diffusion) |
| **复用型** | 调制信号相似时跳过全部 28 层,直接复用上次残差 | TeaCache (CVPR 2025)、TaylorSeer |

**总体目标**:
1. **理论上**分析现有加速方法在**数据分布偏移**下的不足,建立可验证的误差分析框架;
2. **方法论上**提出**通用的、即插即用的改进框架**,能适用于并改进现有加速方法。

---

## 二、原始动机

### 2.1 痛点:分布偏移下,启发式加速的性能退化

现有方法都是**离线标定 + 固定调度**:阈值、缓存系数在标定分布上确定后不再变化。当输入分布偏离标定分布(域迁移、类别不平衡、长尾数据)时,近似质量下降,而"何时刷新"的决策机制对此不可见——质量-速度权衡显著退化。

**分布偏移并非假想,我们已有直接证据**:

1. **per-class γ 标定实验**:不同 ImageNet 类别的最优 γ 横跨 **2.7×**(缓存敏感类需 γ=0.15 全量计算,缓存鲁棒类可 γ=0.40 安全跳过 64% 步)。
2. **类子集偏移定量验证(200 图, 官方 TeaCache 状态机)**:对"缓存敏感类"子集(其类最优 γ=0.15),静态 γ=0.25 下的 latent MSE 是类最优配置的 **10 倍**(0.00060 vs 0.00006);γ=0.40 时恶化到 28 倍(0.00167)。**任何单一全局阈值在类分布偏移下必然在"过度保守"与"质量退化"之间失衡**。

### 2.2 一个同构类比:大模型投机解码(Speculative Decoding)

投机解码的加速比由**草稿接受率**决定;在**未知领域/域外输入**上接受率显著下降,加速比随之退化——这是 LLM 领域已被广泛研究的问题(域依赖接受率、EAGLE3 的分布对齐讨论、领域草稿模型训练等)。

**扩散缓存/外推与投机解码同构**:"近似输出是否被接受"(是否触发 full 计算)≈ 草稿 token 是否被验证接受;缓存/外推准确性 ≈ 接受率;分布偏移下两者都退化。

### 2.3 被浪费的免费信号 → 飞轮设想

在 TeaCache / SpecA 运行中,存在**免费但被浪费的负反馈信号**:SpecA 每次 Taylor 近似都会在 check_layer 做"预测 vs 真实"误差探测(零成本);TeaCache 的调制信号差值同样每步免费产生。

**直觉**:这些信号蕴含"当前近似有多危险"的信息——若能在推理中感知近似质量退化并自适应调整,就能在分布偏移下**维持**加速性能(接受率问题的扩散版本)。

**最初设想**:提出即插即用的**在线负反馈学习框架**(在线阈值校准、持续训练修正器、策略选择 bandit),叠加在现有加速器上,实现自适应 + 飞轮效应。

## 三、探索历程:从"飞轮"设想到机制发现

### 3.1 第一阶段:在线学习方案,系统性证伪

| 方案 | 一句话死因 |
|------|-----------|
| **VFL**(Verification Feedback Loop:在线阈值校准 + 分层回放 + 异步 LoRA) | **决策层(L1 阈值校准)成功:FID -0.22;内容层(L3 LoRA 修正)三次失败**(FID +5.12 → +7.33,target signal 错配)——见下"关键分野" |
| COVR(在线选择刷新模板的 bandit) | SpecA 上有效,TeaCache 上完全失效(见下) |
| TTT(小插件蒸馏修正缓存) | 训练开销吃掉加速收益 |
| Curvature-LoRA(平滑骨干轨迹) | 曲率降 63% 仅转化 6.6% 稳定性 |
| per-image γ 自适应(廉价信号调阈值) | 所有免费信号与缓存敏感性的相关性 < 0.3;raw_diff 跨图相关 0.992(图片无关) |

**结论一:免费信号的增量信息量不足以覆盖学习成本——"通用在线学习"路线不成立。**

**关键分野(最重要的一条线索)**:回顾所有尝试,有一个清晰的规律——**"决策层"学习(改阈值/调度:VFL L1、COVR)全部成立;所有"内容层"学习(改缓存/骨干输出:VFL L3 的三次设计、TTT、Curvature-LoRA)全部失败或无效**。失败根因分析显示,内容修正面临不可回避的结构性困难:学习信号只来自低误差区域(选择偏差)、中间层误差与最终质量脱节(代理目标失真)、修正器改变自身输入分布(分布漂移)、没有质量信号闭环。**这个"决策 vs 内容"的分野,后来被我们的误差结构理论完整解释(见 3.3)。**

### 3.2 一个成功与一个失败:COVR 的迁移悖论

COVR 在 SpecA 上取得显著收益(50k: FID 23.96 → **17.48**),但**同样的框架移植到 TeaCache 上收益完全消失**。我们花了大量时间试图移植,反复失败。

**结论二:这暴露了一个更本质的问题——SpecA 和 TeaCache 不是同一个东西,需要不同的策略。**

### 3.3 调整:从"学什么"转向"为什么"——误差结构诊断

我们放弃直接设计方法,重新思考这两种缓存复用策略的**根本区别**:为什么同一个框架在一类上表现良好,在另一类上表现不好?

**分析工具:误差-距离曲线**(在全量参考轨迹上,模拟"距上次缓存 d 步"的预测误差):

| 跳过距离 d | 外推型(SpecA) | 复用型(TeaCache) |
|-----------|--------------|------------------|
| 1 | 0.0046 | 0.0086 |
| 10 | **0.2190(48×,超线性)** | **0.0611(7×,饱和)** |

分析发现,两种策略的根本区别在于**误差对"跳过距离"的敏感度**:

- **外推型(SpecA)**:误差随时间步**超线性增长**——跳过越远,猜得越离谱(≈d²,和 Taylor 截断误差的理论界一致)。所以"在哪个时间步选择跳过"是**决定性因素**:刷新位置选对了,误差直接被控制住。这就是自适应的真实杠杆——COVR 在 SpecA 上有效,正是因为它优化的是这个决定性变量。
- **阈值型(TeaCache)**:误差和跳过距离**几乎无关(饱和)**——因为它只是把上次的残差原样搬过来,没有外推,误差主要来自"输入变了但残差没更新",而这一步已经被它自己的累积触发机制(γ 阈值)控制住了。所以"在哪刷新"根本不重要,唯一能调的就是那个 γ 阈值,而且阈值只有几个有效档位。这就是 COVR 在 TeaCache 上失效的原因——它在选刷新位置,而位置在 TeaCache 上不影响误差,白选。

进一步定位误差的分布,还有三个维度:

- **时间上**:误差几乎全在去噪**晚期**爆发(早期 40 倍)——所以"晚期多算几步"比"均匀撒步"划算得多;
- **层上**:中层(layer 7-17)误差增长最陡,比当前默认的探测层更值得盯;
- **token 上**:各 token 差不多均匀(和世界模型里少数 token 拖后腿的长尾分布形成对比——那个场景下 WorldCache 的按 token 分组才有意义)。

最后,这个框架还解释了"改决策成立、改内容失败"的分野:

- **改决策**(阈值/刷新位置):动作直接改变误差,且错了能探测到、能回退(安全网);
- **改内容**(修正缓存/微调骨干):学习信号只来自低误差区,中间层误差≠最终质量,越修输入分布越变,还无法验证——失败是结构性的。

## 四、方法论:诊断驱动 + 杠杆再造

### 4.1 诊断协议(1 分钟/模型)

给定任意加速器,跑一次全量参考轨迹,测:① 误差-距离曲线(杠杆是否存在);② 维度定位(时间/层/token 哪个异质,决定自适应粒度)。

### 4.2 结构感知设计(杠杆存在时:优化"在哪里刷新")

按诊断结果(晚期误差主导),为 SpecA 设计**时间桶差异化调度**(早期激进、晚期限距),20 图验证:

| 调度(early, mid, late) | latent MSE | skip% |
|------------------------|-----------|-------|
| uniform (4,4,4) | 0.00088 | 76.1% |
| **sched_a (8,4,2)** | **0.00073(-17%)** | 75.9%(同预算) |
| sched_b (8,4,1) | 0.00055(-37%) | 70.0% |

### 4.3 杠杆再造(杠杆缺失时:重构误差结构)

给 TeaCache 的 skip 步引入**残差线性漂移外推**(`x + res + (res - res_prev)`),误差结构重新变得随距离可优化。12 图 closed-loop 验证:

| 配置 | latent MSE | skip% |
|------|-----------|-------|
| plain γ=0.25(现状) | 0.00510 | 74.7% |
| **linear γ=0.25** | **0.00240(-53%)** | 74.7%(同) |
| **linear γ=0.70** | 0.00919 | **88.2%** |

**决定性对比**:linear γ=0.70 的误差与 plain γ=0.35 相当,但 skip 88% vs 81%——**再造杠杆后,γ 从离散档位变成连续可推的旋钮**。

### 4.4 与最新工作的关系

WorldCache(ICML 2026)在多模态世界模型上按 token 曲率分组(稳定→复用、线性→外推、混沌→阻尼)。我们的诊断实验恰好从机制上解释了它为何成功(给复用型缓存引入外推 = 杠杆再造),并界定了其适用范围(token 级分组在 DiT 上不适用,因为 DiT 的 token 误差均匀)。

## 五、初步验证结果(5k 图,ImageNet, 50 步, CFG=4.5)

| 配置 | FID ↓ | IS ↑ | skip% | 速度 |
|------|-------|------|-------|------|
| TeaCache plain γ=0.25(现状) | 34.82 | 230.65 | 32% | 5.4 img/s |
| **TeaCache linear γ=0.70(本文)** | **34.40** | 229.09 | **70%** | **10.9 img/s** |
| SpecA uniform(现状) | 34.46 | 223.03 | 73.8% | 6.4 img/s |
| SpecA sched_a (8,4,2) | 34.55 | 219.29 | 75.1% | 6.3 img/s |
| SpecA sched_b (8,4,1) | 34.71 | 220.60 | 69.9% | 6.2 img/s |

**如实记录**:
1. **TeaCache 杠杆再造(DiT):严格支配原版**——skip 率翻倍、速度 2 倍,FID 不降反升。当前最稳健的正结果。
2. **跨模型验证(PixArt + COCO, 2000 图, 20 步)**:**同 skip 率(45%)下 linear 优于 plain(FID 403.50→401.88)**——杠杆再造的收益跨模型成立;把 γ 推到 0.70 可再换 +58% 速度,但 FID 略退化(+5.2,γ 过于激进)——**外推机制本身是模型无关的,γ 档位是模型相关的,需各自标定**(PixArt 与 DiT 的系数标定分布不同)。
3. **SpecA 结构感知调度:latent-MSE 层面显著(-17%/-37%),但 5k FID 层面确认未复现**(sched_a +0.09、sched_b +0.25,均在 5k 噪声带内)。这一"代理指标与最终指标脱节"的不一致本身是有价值的发现(中间隔着 28 层 + 尾投影 + VAE 解码 + 分布统计,latent 欧氏距离不能代表生成分布质量),是理论分析要研究的问题。

## 六、当前结论

1. **"在线学习/飞轮"作为通用动机不成立**——免费信号信息量与学习成本不匹配(系统性证伪);
2. **但失败揭示了一个更本质的问题**:加速器的误差结构(误差-距离曲线)决定自适应决策的杠杆空间。**外推型与复用型是两种族类,需要不同策略**——这正是移植失败的根本原因;
3. **两条可行路径已初步验证**:杠杆存在时做**结构感知设计**(同预算免费提升);杠杆缺失时做**杠杆再造**(打开新的自适应空间)。

## 七、下一步计划

### 7.1 理论分析:分布偏移下的误差上界(目标 1)

将"误差-距离结构"形式化为**分布偏移下的误差上界**:
- 复用型缓存:输入分布漂移下残差累积误差的界;
- 外推型缓存:轨迹曲率变化下截断误差的界,给出"自适应刷新"的必要条件;
- 用诊断协议作为通用工具,并用现成 OOD 基准(Places / SUN / iNaturalist)定量验证"分布偏移 → 加速退化"。

### 7.2 通用方法论/框架(目标 2)

基于已验证的机制,构建跨加速器、跨模型的通用框架(三层):
1. **诊断层**:误差-距离曲线 + 维度定位(已实现,1 分钟/模型);
2. **设计层**:按诊断结果选择 结构感知调度 / 杠杆再造 / 档位自适应;
3. **验证层**:推广到更多加速器结构(层间缓存、混合预测器)与更多模型(PixArt 跨模型验证进行中)。
